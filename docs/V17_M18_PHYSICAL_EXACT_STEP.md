# V17-M18 — one original-root physical exact Boolean transaction

**Scope:** explicitly opt-in C++ worker policy, **default OFF** in desktop and existing
brush constructors. This is the first physical post-sculpt V17 union gate,
not the repeated 16-stamp M11 tower/4D queue recovery acceptance and not
the eventual M15 live desktop switch.

## Execution and publication boundary

A `VersionedSculptBrush::stamp` runs the existing private
normal-driven `VersionedInflateBrush`, local refine and local collapse.
When `SculptCollisionSettings::physicalExact=true`, and only if the older
V16 approximate `enabled` setting is false, it then:

1. Calls M17 `assessPostSculptOriginalContacts` on the **actual
   unpublished, post-remesh candidate**, with ALL live source FaceId
   contacts, finite V13 sections and complete symmetry involution.
   **Clean** permits the ordinary clean physical displacement to commit
   without an invented weld. **Refused** never yields a usable source list,
   partial root or history. **CompleteTransverse** is only source evidence,
   not permission to publish.
2. Calls M09 `prepareExactCutStep` with precisely that candidate-root
   pointer, complete original FaceId contact list, exact bounded
   c1/c2/c3/M03/d2 policy and full candidate mirror map. No V16 approximate
   zip, guessed cavity or coordinate-nearest weld is permitted. The
   private cut, classified retirement, source-authorized seam splits and
   private terminal weld never become published roots.
3. Validates that the exact result's `expected` is the actual private
   candidate, with the returned commit pointing to the final revision.
   Applies cut/join mirror additions/removals to *speculative* refiner
   and collapser journals. Refiner's pre-union locally inserted IDs and
   Collapser's pre-union removed IDs are taken into account before this
   stage, rather than reading the pre-brush historical map as the exact
   source. Every final VertexId has a reciprocal/self mirror entry at
   exact reflected XYZ, and all surviving old IDs keep their original
   partner.
4. Compares original **Inflate** mirror orbits with the terminal
   speculative map to calculate NET inserted and retired orbit pairs.
   A vertex allocated by local refinement then retired by collapse
   or the private Boolean contributes neither a historical addition
   nor a historical original-root retirement. A genuine original
   fixed X=0 ID retires through one (id,id) entry; off-plane pairs
   remain two distinct VertexIds. The journal contains no map-wide
   replacement, coordinate equality shortcut or orphan half-orbit.
5. Extends original physical dirty vertex/face sets with exact net
   added, rewritten and retired stable IDs. Runs the selected terminal
   sculpt validator before publication. Computes the render-dirty
   owner union from *original root to final root*, including local
   remesh and Boolean, rather than publishing the cut or post-Inflate
   root. One original-root `publishIfCurrent(old,final)` makes the
   validated final index and revision visible atomically. Only then
   does Inflate acquire the NET new/retired mirrors and exactly one
   history record receive the final root, dirty owners, net mirror
   journal, accumulated COW payload costs and corrected live ID
   counts. The stamp is one FIFO 4D input and one undo transition.

A physical source refusal, failed exact geometry/cavity/winding/vertex
link/collision check, mirror mismatch, budget limit, or user validator
refusal rolls back BOTH speculative remesh maps and leaves old
renderer/picker root, Inflate history/checkpoint map, dirty set and
undo stack unchanged. The next input is still allowed. Failures
*after* the successful final CAS are not mislabeled recoverable;
that exceptional consistency/fault-injection boundary remains
V17-M14.

## Acceptance cases

- **True supported off-plane asymmetric stamp:** the complete three-
  original-contact two-closed-tetra V16/M16 source accepts actual
  normal-driven vertex movement followed by a private 2→1 exact
  joined terminal root. One CAS, zero remaining V13 contacts, stable
  original retired FaceIds, one undo/redo, one durable final checkpoint.
- **Genuinely new collision:** two initially disjoint and individually
  closed tetrahedra are expanded by an actual Inflate stamp across a
  gap. At least one finite-source configuration must pass BOTH the
  M17 full post-motion source certificate and a REAL private exact
  Boolean step and finish as a single undoable physical root. A
  successful refusal is NOT counted as a positive.
- **Reflected two-half stamp:** a real two-area physical movement
  starts with explicit historical reciprocal ID pairs. One exact
  original-root mirrored union must leave only live, geometrically
  reflected pairs in all three mirror controllers, history and
  durable checkpoint. Undo restores precisely the old sorted
  historical pairs; redo restores the exact terminal immutable root.
- **Refusal then progress:** an insufficient full source-section
  budget refuses without root/undo/dirty publication; a deliberately
  terminal-validator-refused complete symmetric source join rolls
  back speculative pair journals, and an identical later valid
  physical stamp succeeds. The actual queued worker's initial 4D
  physical input must publish the same terminal full root, never an
  intermediate explicit Merge command or empty synthetic Step.
- **Remesh boundary:** an actual local edge split after Inflate
  allocates a new stable vertex; complete post-refine original FaceId
  coverage must either pass exact closure as one original-root Step
  or refuse atomically. No partial refinement publication, mirror
  delta or stale pre-remesh FaceId source list is allowed.

## Explicit non-goals and next tasks

The tester deliberately chooses the bounded M04/M08/M16 exact
source-proven geometry. No general guarantee is made for arbitrary
N-sheet, tangent, coplanar, invalid imported, near-degenerate or
resource-exhausting geometries. The unrelated valid identities
at coincident XYZ remain protected by M16. The existing source
witness/hysteresis cumulative policy remains M12, aggregate live
work accounting M13, exceptional post-CAS consistency M14 and
the default-OFF desktop option M15. **Original M11** must still
demonstrate sixteen repeated *actual*, alternating symmetric physical
union Steps, FIFO drain, clean/refused continuation, stale/undo and
checkpoint recovery.
