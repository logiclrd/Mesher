## What was accepted

M20 required source-owned living descendants of a first-original
protected FaceId across actually committed local remesh and full
original-root exact Boolean joins; it was **not** an instruction to
assign surfaces by XYZ proximity. The accepted scope is finite,
source-ID exact and intentionally conservative. Each stage's existing
independent positive and negative regressions remains mandatory:

| Required original M20 proof | Verified mechanism and independently completed gate |
|---|---|
| Original permanent FaceId and immutable first sampling reference | M19 captures the true first topology root and seven fixed witnesses in each original triangle's smallest-edge units; M27 retains this same root across revisions |
| Real split and rewritten source parent faces | M24 journals before/after RegionEdit commits and the oriented directed two-child subdivision; rewritten same FaceId plus appended child both stay associated with exactly one original owner |
| Real 2-to-2 flip and source-patch transfer | M25 checks the exact oriented four-edge permanent-ID boundary, actual original source ownership and conservation; ambiguous cross-original protected transfers refuse rather than fabricating joint ownership |
| Real collapse retirement/rewrite with protected surface safety | M25 checks every affected original halo, tombstone, midpoint, paired mirror and rewritten face from accepted RegionEdit; a candidate that deletes/moves unexempted protected Exposed/ReversedBoundary material **refuses** (M21 still owns deliberate intent) |
| Exact cut and join surviving children | M26 independently reruns original-contact c1/c2/c3 and M03 decisions using saved private cut evidence, then connects first originals to only truly live d2 terminal child FaceIds |
| Legitimate hidden source material removal | Complete source-certified c3 Buried/Outside children and M03 uncut burial may have no living descendants, with explicit retired-original authority; exposed exterior/reversed cavity children may not silently disappear |
| Mirrored off-plane, X=0 self-orbits and coincident independent sheets | M24/M25/M26 source-proven partner vertex/face journals and M27 opaque original-owner certificate; mirror reflection does NOT invent cross-sheet vertex or FaceId aliases from XYZ |
| Bounded descendant audit across published revisions | M27 seals the immutable first/terminal pointers, owner graph, accepted transitions, retired originals and cumulative proof cost; exactly 7 × ALL live source descendants sampled against their OWN first-original witnesses only |
| Atomic refusal and no partial success | Each stage verifies its own complete source/root/journal budgets; missing/ambiguous/forged/stale ancestry and one-below work limits refuse; no failed private edit can publish half a union |

## New M20 integration regression beyond independently accepted peers

`tests/revision_collision_tests.cpp` uses the existing real two
closed-tetrahedral-surface union, which already has genuine complete
original-contact coverage and a c3/M03/d2 terminal union.

The added test begins an M27 lineage for **all eight original faces**,
certifies the exact union and its Buried/Outside outcomes under the
original M26 source graph, then performs a **new real committed M24
edge split** on the union's terminal topology. The resulting single
lifetime must preserve the first original root, previously certified
complete retirements, live original-owned face descendants and the
original seven-point scales. This does **not** start a new lifetime
at the post-union root.

The test publishes first the complete Boolean terminal revision
and then the actual separately committed remesh revision through
two successful `IndexedMeshRepository::publishIfCurrent` calls.
A stale original-root CAS refuses; the immutable first historical
picking root remains valid. The cumulative original-source face
evidence cap must equal *prior M26 work + actual M24 split source
records*; one less refuses. A complete per-original 7×live-child
distance audit passes at exact work cost and refuses one less. An
attempt to exchange unrelated original-owned children refuses,
even when their coordinates may coincide.

This tests a genuinely shared source lifetime **across stage
boundaries**, rather than only verifying the individual M24–M27
APIs in isolation. It does not weaken the existing c1/c2/c3/M03/d2
predicates or change any mesh publication implementation.

## Result and remaining boundaries

#39168754914](https://github.com/logiclrd/Mesher/actions/runs/39168754914)

and conservative same-original-owner flip rule are intentional
source-proof safety boundaries, not authority for automatic
destruction of protected geometry. These boundaries are handed to:

- **M21:** explicit intended sculpt displacement, scoped first-original
  source exemptions, complete cavity/exposed policy and refusals.
- **M22:** active cumulative first-original terminal fidelity decision
  BEFORE original-root CAS, including rollback/picker/worker state.

- **M12:** final integrated original-anchored fidelity acceptance.
- **M13–M16, V18 and V19:** original separately preserved work.

The finite seven-point first-original directional audit remains
**one-sided sampled evidence**, not continuous two-sided Hausdorff
or a proof against all high-curvature degradation. The desktop
Merge geometry option remains default-disabled.
