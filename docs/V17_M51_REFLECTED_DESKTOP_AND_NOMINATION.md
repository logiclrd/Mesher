## Supported developer-only source

New `--merge-test-reflected-tetra` is available only with both
`--merge-geometry` and `--symmetric`. It cannot be combined with
the M50 asymmetric fixture, with disk-only `--recover`, with demo,
comparison or noninteractive start. Normal launch remains the same
legacy Mouse Inflate worker. With the explicitly named reflected
fixture, actual `src/main.cpp` builds the same reflected 16-vertex,
16-triangle original as the previously accepted M47/M49 regression:
independent positive-X source tetrahedra are translated by +5,
with eight *new* negative-X source vertices at the exact reflection
and reversed-wound source triangles.

`desktopMergeReflectedFirstOriginal()` **does not infer mirrors from XYZ**.
It performs an original partition import, retains its exact initial
immutable indexed root, binds corresponding old indexed
`VertexIds[i]` with `VertexIds[i+8]` for each of eight **independently
source-proven reciprocal pairs**, captures each original `FaceId` and
seven fixed anchors, and begins sealed M29 first-original source lifetime.
It returns a trusted *in-memory* `DurableCheckpoint` whose separately
verified first original mirror map is preserved for the worker. The
real `AsyncSculptWorker(DurableCheckpoint,...trustedFirstFaces)` checks
that certificate and source authority: a disk-read V13 checkpoint
cannot turn into this privileged source. The production exact
`physicalExact` worker and immutable source root remain unchanged. Both
viewport GPU projection and CPU ray picking consistently apply a
**fixture-only** positive camera distance scale: 2.0 for the original
asymmetric test scene, 4.0 for off-plane reflected groups at X≈±5.
Normal unit-sphere launch keeps cameraScale=1.0. This is *framing* for
an otherwise invisible test scene, not a source-geometry transform
or a substitute for real observed Linux/Windows Vulkan acceptance.
No automatic Boolean, source selection or root publication is triggered
merely by launching the fixture.

## Explicit hidden-source nomination

In the named asymmetric or reflected developer fixture only, pressing
**M** first enables ON; pressing **A** deliberately requests nomination
of **every original FaceId** in the finite tested fixture (8 or 16),
including visually occluded originals. Pressing Enter then submits the
exact current indexed root and only those explicit IDs to the
unchanged M47 single-writer FIFO discovery and strict c1/c2/c3/M03/d2
Boolean. Mouse picks may precede A; their IDs remain unchanged and
no duplicates are introduced. Merely pressing A does not execute a
Boolean. Backspace, M OFF, or a new rendered root clears selections.

The real GLFW A rising-edge detector and
`DesktopMergeInput::nominateFixtureOriginals` (the actual viewport
controller) require ON, idle, an exact
`displayedRoot == originallyCapturedFixtureRoot`, a unique list
of nonzero currently living stable FaceIds and no more than 32
distinct IDs combined with existing picks. A **whole-list preflight**
performs no spatial contact query and no coordinate/nearest/mirror
guessing; a foreign/duplicated/invalid/33rd, stale or busy nomination
refuses atomically without partial selection. The ordinary generated
sphere has **no fixture source list**, therefore A cannot promote it
to a hidden all-original authorization. The worker independently
rechecks first-original IDs, true reciprocal symmetry, source
lineage/certificate, complete original contacts, signed-winding and
cavity safety, all 38 live resource ceilings, terminal geometry,
one-CAS publication and post-CAS fail-stop. The normal 32-click UI cap,
displayed root fencing, protected no-disk-resurrection and default OFF
remain unchanged.
