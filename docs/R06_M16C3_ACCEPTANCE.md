## New opt-in execution path

`include/mesher/repair_step_trace.hpp` combines the already accepted M16C1 `RepairStepGate<RepairStepGeometry>`, M16C2b immutable per-operation geometry packets, and C2c typed terminal reports. The trace installs callbacks in `MixedPrivateClosureLimits` only when an owning `std::shared_ptr<RepairStepTrace>` is explicitly supplied; no snapshots or pauses are generated by default.

`replayPrivateAutomaticRepair(..., std::shared_ptr<RepairStepTrace>)` now supports opt-in observation of the real R02 -> R03 -> M03 classifier -> M04B staging/refinement -> M04C certified private closure. The existing `--repair-replay` and `--repair-replay-test` modes supply **no** trace and remain synchronous, unchanged. This milestone is **API/CPU only**: there is no CLI switch to activate this trace and no Vulkan step UI yet.

- Producer blocks after a coherent logical staging mutation; consumer receives an owned immutable frame with an R03 source pointer, exact source overrides, generated faces/positions and live boundary diagnostics.
- `next()` releases exactly one operation; `showPrevious()`/`showCurrent()` affect displayed frames only; `continueRunning()` disables the remaining pauses; `cancel()` wakes the blocked producer and preserves `RepairStepCancelled`.
- The operation event stores exact name/arguments and is bounded by the existing snapshot byte limit. The gate retains only current and previous frames.
- A separate mutex-protected bounded terminal list reports M04B `Completed`/`Refused`/`ObserverFailed` events as well as the higher-level `certified_auto` result and any pre-R03/planner refusal. An M04B `Completed` event is **not** equivalent to final M04C publication authority. All these indices are private and remain unpublished.
- A warning-only preview, if requested, gets the explicit `UNTRUSTED_QUALITY_WARNING_PREVIEW` prefix in each frame and terminal `untrustedWarningPreview=true`. It does not silently replace a refused strict result.
- `runAutomaticClosure` uses a small RAII guard to mark the gate finished on normal return, refusal and cancellation. It specially rethrows `RepairStepCancelled` and `RepairStepObserverFailure` instead of converting either into a geometry refusal or triggering warning-only fallback. No worker-root CAS, history, checkpoint or GPU call is performed by step callbacks.

## Exact saved-case headless acceptance

`tests/repair_step_replay_tests.cpp` creates a real 5,000-vertex torus candidate, derives stable R01 contact IDs, writes a real `.r06case` file and **reads it back** through the production serializer before the following tests:

1. **Normal versus traced real automatic closure:** run baseline synchronously; spawn a separate CPU worker with trace; wait for initial frame; release exactly one Next; receive the second frame; inspect Previous/Current and diff without advancing; Continue to final private M04C certification and join.
2. **Equivalence:** classifier's cap contour selection, generated face count, post-retirement face count, refinement steps, closure diagnostic and source identity/retirement invariants match untraced replay. Final terminal record must be `certified_auto` `Completed`.
3. **Cancellation:** a fresh 5K repair runs on a separate worker, pauses at first stage operation, is cancelled and joined; its `RepairStepCancelled` is not swallowed or turned into `Refused`, and original source/captured frame remain immutable.
4. **Real refusal provenance:** the same exact contact case is deliberately marked intrinsically symmetric where the geometry is not; traced and untraced runs refuse identically, with an explicit terminal `Refused`, not a fabricated publication or warning-only preview.
5. Existing M16C1/C2a/C2b/C2c and archival exact replay regressions remain in the unchanged full CI suite.
