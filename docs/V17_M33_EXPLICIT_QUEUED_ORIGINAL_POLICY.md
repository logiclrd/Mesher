## Boundary and decision

M32 protected the normal-driven full physical stamp and refused a
separately queued explicit source-exact command when the M29 history
was authenticated. A late M29 null-proof failure after publishing
would violate atomic old-root CAS. M33 upgrades THAT queued command,
not the default desktop Merge geometry mode. Untracked legacy queues
are intentionally unchanged.

The request includes a caller-chosen exact expected COW root,
a complete explicit contact graph, bounded `ExactCutStepLimits` and
caller-nominated FIRST-original FaceIds. The actual current published
index and `history_.currentFidelity()` must match the expected
root and the immutable original source anchors. A protected
source-less recovered V12/V13 root or a fresh opt-in `physicalExact`
session without true first-root evidence is NEVER permitted to use
an untracked fallback.

After the original contact classifier/c1/c2/c3/M03/d2 private
transaction and mirror delta checks succeed, the worker executes
the following BEFORE any mutable controller journals, CAS or
history/renderer snapshot change:

1. Verify the predecessor is the exact current authenticated M29
   sealed lifetime for the expected OLD root, with the SAME first
   original anchor owner and permanent original FaceId identities.
2. Enforce a finite bound on raw caller FaceId nominations before
   reserving/filtering. Preserve explicit successive-Step authorizations
   of previously sculpted still-live source patches; omit a now-retired
   named origin from the active M21 declaration only if its WHOLE
   original Buried/Outside retirement was independently certified by
   M26. Foreign, duplicate, null and half-reflection selections refuse.
3. Use the **actual current old-root** live reciprocal mirror map
   when re-verifying M26's genuine c1/c2/c3/M03/d2 source cut, all
   parent/child source owner arrays, legal c3 retirement, net d2
   surviving FaceIds, reflected fixed-point and off-plane orbits,
   source budgets and complete final terminal root.
4. Independently use M31's permanently ORIGINAL-root VertexId
   involution for M21 intended-face closure, including X=0 singleton
   orbits. The two roles must never be interchanged or reconstructed
   from XYZ coincidence.
5. Verify the one externally visible successor's direct opaque
   parent certificate, original owner, exact old/final roots,
   nonregressed cumulative evidence and BOTH configured and default
   M29 append proof limits. Evaluate every nonretired first-original
   source's seven immutable XYZ witness samples against ONLY its
   certified living permanent FaceId descendants, measured in its
   own original shortest-edge scale. Intent exempts a geometric
   deviation threshold only; neither source identity, work cap nor
   a disappearing protected cavity wall.
6. Only after all verification may one original-root indexed CAS
   publish the **final welded** c1/c2/c3/M03/d2 result, apply the
   net mirrored controller journal and append the exact single M29
   root/dirty/history/source certificate. The renderer and picker
   never see partial cuts.

All pre-CAS stale, malformed, exceeded finite work and deviation
refusals leave existing live root, redo branch, all controller mirror
pairs, dirty partitions and trusted source history/checkpoint intact.
The original COW reader/picker remains valid across acceptance and
refusal. Explicit source input is scoped to each command; nothing
is inferred from geometric proximity or permanently exempted.

## Acceptance

- Genuine asymmetric original intersection union first rejects a
  foreign FaceId, then accepts all caller-named FIRST-original sources
  with ONE final CAS and dirty owner set; a later stale expected
  root refuses without a new renderer mailbox entry or history.
- Exact complete first-original seven-witness work accepts; one
  comparison below refuses. Likewise exact M26 cumulative source-face
  evidence accepts and one-under refuses. Oversized RAW original
  FaceId input refuses before filtering certified-retired origins.
- A source-less V12-derived opt-in `physicalExact` queued union
  cannot bypass the source history gate. Accepted protected
  V13 disk checkpoints remain marked provenance-required but cannot
  synthesize a sealed original certificate on binary reload.
- The source-complete three-contact X=0 fixed-point reflected union
  accepts with singleton and reciprocal original/source IDs, while
  two-of-three contacts and a half-reflected original FaceId
  declaration refuse atomically. Undo/redo preserves exact COW roots,
  mirror history and sealed original source lifetime.
- A private original-root transaction with deliberately insufficient
  `maxNetChangedIds` preserves an existing redo branch after undo.
  A supported next request can still drain in the same FIFO worker.

## Remaining work

M34 combines both authenticated physical and queued union paths across
serialized true 4D FIFO, alternate same-patch contacts, protected
cavity and mirrors, and concurrent checkpoint/render/picker acceptance.
Original M30 and M22 cannot close until that integrated gate.
Original M23 and M12, M13–M15, V18/V19 and M14 post-CAS injected
exception acceptance remain separately OPEN. Desktop Merge geometry
remains default disabled.

The result is a **finite sampled one-sided first-original source
policy**, not a continuous Hausdorff bound, universal imported-mesh
semantics, all CCD, or proof of user-visible desktop readiness.
