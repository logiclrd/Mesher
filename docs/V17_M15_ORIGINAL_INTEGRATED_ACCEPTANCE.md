## Original product gate and two distinct modes

The original M15 objective is **opt-in Merge geometry = On** only
for independently source-proven supported geometry, while previous
ordinary desktop behavior remains **Off**.

- Ordinary `Mesher` has legacy Mouse Inflate, no M29 source
  authority and M cannot enable Merge; it never auto-welds.
- `Mesher --merge-geometry` deliberately provisions an authenticated
  FIRST-original in-memory `physicalExact` worker, **but UI Merge
  selection starts OFF**. OFF retains the launch-configured
  normal-driven protected physical policy, not the ordinary unarmed
  legacy worker. Pressing M while idle turns ON source selection;
  unmodified LMB picks first-original stable FaceIds instead of
  stamping. Only Enter deliberately queues a complete authenticated
  worker-side original-contact discovery/Boolean. Switching OFF,
  Backspace and new displayed roots invalidate prior selection.
- This separation is enforced by the actual `DesktopMergeInput`
  called from `src/viewport.cpp`, not a mock controller. M47
  `DiscoverMerge` uses the same serialized FIFO as physical
  Begin/End, undo, redo and checkpoint; the render thread never
  performs unbounded complete source discovery.
- Protected `--merge-geometry --recover` without an M29 sealed
  in-memory source certificate refuses. V13 disk includes a
  fidelity-required marker, **not** a serializable opaque lifetime.
  Denial is intentional, not failed acceptance.

## Original V17-M15 acceptance decision and retained nonclaims

**Accepted** for the original declared bounded, source-proven
desktop + real-protected-physical intersection domain with independently
verified positive and conservative-refusal paths, the supported
source/protected original and hysteresis behavior, actual 38-dimensional
finite Step admission, immutable one-CAS publication with exact
history/picker/dirty sources, M14 terminal failure handling, intended
disk checkpoint policy and manually observed Linux/Windows UI.
This is a **criterion-by-criterion final integration of independently
accepted code paths**, NOT a new synthetic umbrella fixture, universal
"mesh merge" feature or removal of any original M15 requirement.

Remain separately **OPEN / OUT OF SCOPE**:
- **V18:** opt-in OFF-mode prevention of *new* nonadjacent crossings;
  current OFF behavior is not guaranteed swept CCD.
- **V19:** imported scans, arbitrary near-degenerate/coplanar,
  grazing, tunnel, higher-genus/multicontact Boolean, large 5k/20k/
  100k+ device performance and memory/latency/release stress.
- **M66:** optional backface culling; current two-sided interior
  visibility is intentional, not a topological defect.
- **M70/M71:** symmetric→asymmetric editing and spatially mirrored
  strokes on intrinsically asymmetric topology (no forged reciprocal
  stable IDs).
- **M72:** persistence of runtime sculpt flags/settings in disk
  checkpoints; M73 makes ordinary CLI collapse/curvature/refine
  enabled by default and opt-out via `--no-*`, but does not add
  settings serialization.

No unbounded full-root GPU collision search, XYZ-nearest seam welding,
silent reanchoring of FIRST original geometry, implicit dynamic Merge
authorization, global remesh/coarsening, catastrophic post-CAS
pseudo-rollback, universal signed-winding classification or arbitrary
