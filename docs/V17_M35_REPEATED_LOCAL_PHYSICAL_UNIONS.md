## Purpose

The sixteen genuine M11 mirrored physically triggered unions proved repeated
Boolean success on one brush/history, but their original two-tower contacts
were deliberately FAR APART to isolate each complete source-root query.
M12 requires positive repeated actual physical contact in the SAME LOCAL
sculpt neighborhood, not just multiple distant independent tower patches.
A new acceptance case uses TWO independent source-owned closed symmetric
tetra pairs with their SECOND region translated into the FIRST region's
six-unit brush support. The source remains initially collision-free.
Both physical brush footprints share at least one ORIGINAL live
positive-X VertexId candidate returned by spatial sphere queries; this
is a concrete intersecting brush-influence neighborhood, not an
assertion based only on nominal radius or proximity of XYZ labels.

## Real full-root operations

`testM35RepeatedPhysicalUnionsInOneOverlappingPatch` runs two
sequential NORMAL-DRIVEN `VersionedSculptBrush::stamp` operations,
not direct queued `mergeExactContacts`, on ONE opt-in `physicalExact`
brush using the original FaceId intent. The fixture searches a
small fixed finite parameter set of physically separated band distances,
initial gaps and normal-driven strengths, requiring an actual
certified supported pair rather than assuming a previously accepted
single-band stimulus must also work in the overlapping configuration.
Every complete source condition remains active: independent original
FaceIds, no XYZ-nearest ancestor inference, finite original V13
contact and c1/c2/c3/M03/d2 join, post-d2 M21 FIRST-original
living-descendant witness audits, and actual M29 history source
provenance. The test cannot count an unsupported/refused candidate as
a positive result.

Each of the TWO stamp calls must independently report one newly
completed full source union, strictly more permanently retired source
faces than the previous published root, one additional external
original-root COW/history step, zero rejections and real dirty render
partitions. Both successful source checks must observe conclusive
Contact in the SAME still-active episode, without an intervening
three-Clean closure or any reused Boolean approval. Source proof
anchors remain tied to the immutable FIRST imported root and previous
picking/BVH readers retain their pointers. Every live reciprocal
mirror ID in the final merged root must exist and have exactly
reflected XYZ. Two successive undo operations restore the two
exact previous history roots; redo returns the two exact positive
roots in order.

This establishes two independently source-certified physical joins
in overlapping BRUSH SUPPORT that include shared original vertex
candidates. It does NOT assert that the second cut necessarily
connects to the same already welded component, nor that arbitrary
three-source same-shell unions are supported. It does not replace
M36, whose separate scope is simultaneous first-original
exposed/cavity/outer-wall protection, deliberate source exceptions,
cumulative erosion refusal, finite exact/below-budget work,
real 4D episode and later FIFO recovery using a coherent local
sequence. The ORIGINAL V17-M12 checkbox remains open pending
